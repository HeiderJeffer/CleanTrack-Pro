# 🧹 CleanTrack Pro

**Developed by Heider Jeffer** 🧹💙

**CleanTrack Pro** is a smart cleaning time and work management application designed to help cleaning workers track their daily work, room completion, working time, notes, and material consumption.

The project was created to make daily cleaning operations **simpler, more organized, and data-driven**.

## ✨ What CleanTrack Pro Does

CleanTrack Pro allows a worker or supervisor to:

* 🕐 Track available cleaning time
* 🛏️ Track up to 16 rooms per working day
* 📊 Calculate the available time per remaining room
* 📝 Add notes for each room
* 🚿 Track corridor completion
* 📅 Automatically record the working day and date
* 📚 Keep a complete working history
* 📦 Automatically estimate total cleaning-material consumption
* 💧 Track estimated water consumption
* 🧴 Track cleaning-product consumption
* 📥 Export working data to CSV
* 📴 Work offline on a smartphone using the mobile PWA version
* ☁️ Synchronize stored data with Supabase when an internet connection is available

## 📦 Materials & Consumption

The application automatically calculates estimated consumption based on the number of recorded working days.

Current standard rates:

* 💧 **12 liters of water per working day**
* 🧴 **1 bottle of floor & sanitary facilities cleaner per 5 working days**
* 🪟 **1 bottle of glass cleaner per 5 working days**
* 🚿 **1 bottle of bathroom barrier & floor cleaner per 5 working days**

This makes it possible to collect real working data and understand how much water and cleaning material is consumed over time.

## 📱 Mobile & Offline

The mobile version is designed as an **offline-first Progressive Web App (PWA)**.

The worker can use CleanTrack Pro on a smartphone, save information without an internet connection, and synchronize the data with the online database when the connection becomes available.

## 🗄️ Data Collection

CleanTrack Pro is designed not only as a daily cleaning tracker, but also as a **data collection system**.

Over time, the collected information can help analyze:

* Cleaning performance
* Rooms completed per day
* Time spent per room
* Working-day history
* Material consumption
* Water usage
* Cleaning-product requirements

## 🛠️ Technologies

* **Python / Streamlit** — web application
* **JavaScript / HTML / CSS** — offline mobile PWA
* **Supabase** — cloud database and synchronization
* **IndexedDB** — local offline storage
* **Pandas** — data processing and export

## 🎯 Project Goal

The goal of CleanTrack Pro is to transform a simple daily cleaning routine into a **structured digital system** that makes work easier to track, improves organization, and creates useful data for future analysis.
