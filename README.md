### Smart Cleaning Time Tracker

**CleanTrack Pro** is a smart cleaning management application designed to help cleaning workers track their daily work, manage room cleaning, monitor available time, record worker notes, and collect useful working data.

The application is designed around a **16-room daily cleaning schedule**, with working hours from **8:00 AM to 1:00 PM** and a **20-minute break**.

### ✨ Main Features

* 🧹 Track rooms completed and remaining
* ⏱️ Calculate available cleaning time
* 🛏️ Calculate estimated minutes per room
* 🎯 Estimate expected finishing time
* 📝 Add notes for every room
* 📅 Automatically record the working day and date
* 📚 Store and view working history
* 📊 Collect cleaning performance data
* 📦 Automatically calculate total material consumption
* 💧 Track estimated water consumption
* 🧴 Track cleaning-material consumption
* 📥 Export collected data as CSV
* ☁️ Store data in a database using Supabase
* 📱 Designed with mobile use in mind

### 📦 Materials & Consumption

CleanTrack Pro automatically estimates total consumption based on the recorded working days:

* 💧 **Water:** 12 liters per working day
* 🧴 **Floor & Sanitary Facilities Cleaner:** 1 bottle per 5 working days
* 🪟 **Glass Cleaner:** 1 bottle per 5 working days
* 🚿 **Bathroom Barrier & Floor Cleaner:** 1 bottle per 5 working days

### 🎯 Project Goal

The goal of CleanTrack Pro is to turn everyday cleaning activity into **organized, measurable data**.

Instead of relying on paper records, the application collects information about:

**Working Days → Rooms → Time → Notes → Materials → Consumption → History**

This helps make cleaning operations easier to monitor and provides useful data for understanding productivity and material usage.
